# Tenth Avenue Web Design

A full-stack business website for Tenth Avenue Web Design.

The site uses a bold black visual style, neon pink accents, a Lamborghini-inspired hero section, clickable navigation, frontend forms, and a working Express backend that stores enquiries.

## Tech Stack

- Frontend: React and Vite
- Backend: Node.js and Express
- Styling: Custom CSS
- Data storage: JSON file for local development
- Deployment-ready structure for GitHub, Vercel, Netlify, Render, or Railway

## Local Setup

Install dependencies:

npm run install:all

Start frontend and backend together:

npm run dev

Open the website:

http://localhost:5173

Check the backend:

http://localhost:4000/api/health

## Forms

The contact and quote forms submit to the backend.

Local enquiries are stored at:

backend/data/leads.json

## Brand Direction

- Matte black background
- Neon pink primary colour
- Bold typography
- Sports-car inspired hero
- Clean premium agency layout
- No ratings section

## Deployment Notes

GitHub Pages can host the frontend only.

For the full-stack version:

- Frontend: GitHub Pages, Vercel, or Netlify
- Backend: Render, Railway, Fly.io, or a VPS
